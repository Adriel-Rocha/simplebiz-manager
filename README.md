# SimpleBiz Manager

Sistema de gestão para pequenas empresas (API backend em Java + frontend a definir).

## Tecnologias
- Java 17
- Spring Boot
- Spring Security + JWT
- Spring Data JPA
- MySQL
- OpenAPI / Swagger

## Como executar
1. Clonar repositório
2. Configurar banco de dados MySQL
3. Atualizar `application.properties`
4. Executar `mvn spring-boot:run`
